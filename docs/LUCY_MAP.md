# Карта Люси

_Состояние на 11 октября 2026. Живая версия — документ «Карта Люси» у Кристины; этот файл — копия для Claude, GPT и любого, кто работает с кодом._

Люся — Telegram-помощница школы OH MY GOD VINTAGE: шкатулка находок, поиск по библиотеке редких книг Кристины и учёт покупок с флохмарктов.

## Суть и уникальность

Люся — не второй чат GPT. Её ценность в четырёх вещах, которых нет у обычного ИИ:

1. **Библиотека Кристины.** Редкие книги и каталоги, которых нет в открытом доступе. Ответы и исследования опираются на них, со ссылкой на DOC-номер и страницу.
2. **Экспертиза Кристины.** Её знания о клеймах, материалах и истории — в правилах, опросниках и разборах.
3. **Шкатулка, которая продолжает расследование.** Нерешённые загадки не умирают: Люся сообщает, когда в библиотеку пришла книга, где может быть украшение.
4. **Сообщество.** Девочки помогают опознавать друг другу, Кристина даёт экспертное слово.

Два главных сценария:

- **Дома:** разобраться, что за украшение, — эпоха по признакам, поиск в книгах, атрибуция с доказательством.
- **На рынке и после:** быстро сохранить покупку с ценой и вести учёт «куплено — продано» вместо Excel.

Техника: Python, python-telegram-bot, SQLite на Railway (`/data/lucy_vintage.db`), PDF и изображения в Cloudflare R2, OCR Tesseract, ИИ — OpenAI gpt-4.1-mini (только там, где без него нельзя). Бот @LucyVintageBot.

Главный принцип денег: всё, что можно сделать без ИИ, делается без ИИ. Платный вызов — только финальная проверка и только после подтверждения.

## Правила проекта

Эти правила действуют для любого ИИ, который работает с кодом Люси.

- Каждая задача — отдельный PR от актуального main. Ничего не объединять с main самостоятельно — это делает Кристина.
- Не удалять и не менять книги, OCR, индексы, DOC-ID, карточки и их ID. Ничего не удалять автоматически. Миграцию базы — сначала объяснить и согласовать.
- Не переименовывать книги по OCR без подтверждения администратора.
- Платные API — только по согласованию. Перед каждым платным вызовом — проверка лимитов и бюджета. Никакой платной массовой индексации без согласия.
- Не объявлять функцию работающей, пока она не проверена на Railway. Не называть текущее исследование «полноценным визуальным поиском».
- Не обещать пользовательницам «обучение ИИ на их фотографиях».
- Не показывать пользователям секреты и технические ошибки; диагностика — без ключей, ссылок и личных данных.
- Не менять существующие кнопки и функции без необходимости.
- Клеймо, которое вписала владелица, важнее любого чтения ИИ. Отсутствие сведений — не «клейма нет».
- Каждое исправление — с тестами (`python -m unittest discover -s tests`), а причина ошибки объясняется точно, а не предположительно.

## Дорожная карта

Порядок следующих задач. Каждая — отдельный PR; следующая начинается, когда Кристина приняла предыдущую.

1. **Пилот визуального поиска (задача № 1).** Отдельный модуль, не трогает работающую Люсю. Одна книга Sarah Coventry: вырезки украшений → векторы → поиск → экзамен на 20–30 эталонах Кристины.
2. **Визуальный поиск в исследовании.** Если пилот прошёл экзамен: сравнение вырезок вместо целых страниц, в ответе одна вырезка с находкой, кнопка «Я вижу это украшение на странице».
3. **Быстрая покупка и учёт.** Фото с ценой в подписи, статусы «куплено → выставлено → продано», итоги месяца, выгрузка в Excel. ИИ не нужен.
4. **Компактная шкатулка.** Одно сообщение на вещь, статусы расследования, фильтры, альбом миниатюр, правки в том же сообщении.
5. **Группа без участия Кристины.** Посты из библиотеки с её одобрением, «Загадка недели», «Раскрыто на этой неделе». Схема из 13 тем согласована.
6. **Опросник «ценно — неценно».** Когда Кристина напишет вопросы и правила.
7. **Потом:** «Помогите опознать», «Экспертиза Кристины» (Люся PRO), уведомления о новых книгах, Telegram Mini App — как только бета покажет, что девочки реально пользуются.

Параллельно с бетой: спросить девочек, что они приносят с рынков и где застревают. Их ответы могут поменять порядок шагов 3–7.

## Новые функции подробно

### 1. Визуальный поиск по библиотеке

Задача: находить украшение в книгах по картинке, даже если у него нет подписи. Сейчас страницы выбираются по тексту, и ИИ видит только 4 сжатые страницы.

- **Вырезки, а не страницы.** Каждое украшение на странице — отдельная вырезка с координатами (DOC → страница → область). Источники вырезок, все бесплатные: картинки, встроенные в PDF (PyMuPDF достаёт их точно); выделение предметов на светлом фоне для сканов; подстраховка — половины, четверти и сетка 3×3.
- **Отпечатки картинок.** Открытая бесплатная модель (CLIP или SigLIP — выбираем на пилоте) превращает каждую вырезку в вектор. Похожие украшения = близкие векторы.
- **Чёрно-белое перед сравнением.** И фото, и вырезки — чтобы цветное фото не проигрывало старой ч/б рекламе.
- **Индекс строится один раз.** Можно на Mac Кристины (бесплатно) или на Railway (минуты процессора). Векторы лежат в R2. Массовую загрузку книг останавливать не нужно: индекс строится потом по уже загруженным PDF.
- **Поиск и проверка.** Поиск похожих бесплатный (сравнение чисел). Платно только одно: gpt-4.1-mini сравнивает 6–8 крупных вырезок в экономном режиме. По оценке — доли цента за исследование, точнее покажет `/vstats` на пилоте. Бесплатный режим: показать топ похожих вырезок без ИИ, сравнивает сама девочка.
- **Ответ — одна вырезка с находкой и подписью**, ниже кнопка «Показать всю страницу». Если на странице есть номер патента, Люся показывает и его.
- **Экзамен пилота.** 20–30 украшений с известной книгой и страницей (цветные каталоги, ч/б реклама, плохие сканы, много изделий на странице, похожие модели). Цель: правильная вырезка в топ-20 минимум в 90 % случаев; служебных страниц (оглавление, указатель, библиография) среди финальных совпадений — ноль. Замеряем стоимость, скорость и честное «совпадение не найдено».
- **Кнопка «Я вижу это украшение на странице».** Сохраняет проверенный пример для тестов. Это эталон, а не доказательство подлинности и не «обучение ИИ».
- **Честное ограничение.** Поиск находит похожее; окончательное слово — сверка деталей: камни, застёжка, клеймо, подпись в каталоге.

### 2. Быстрая покупка и учёт (замена Excel)

Шкатулка одна, у каждой вещи две стороны: 💶 деньги (цена, место, продажа) и 🔍 расследование. Кому нужно одно — не заполняет другое. ИИ не нужен, токенов ноль.

- **Фото с подписью «20»** → карточка: фото, 20 €, сегодняшняя дата. Одно действие.
- **«20 Мангейм»** → цена и место покупки.
- **Лот:** альбом до 10 фото с подписью «50 лот» → Люся спрашивает: разделить цену поровну или записать на весь лот.
- **Статусы:** куплено → выставлено → продано за 45. Люся считает прибыль на каждой вещи.
- **Итоги:** потрачено за месяц, продано, прибыль. Кнопка «Скачать в Excel».
- **Голос — позже.** Расшифровка речи платная; цена в подписи к фото быстрее. Добавим, если девочки попросят.
- Цены видит только владелица карточки.

### 3. Шкатулка как расследование

Цель: каждая карточка получает что-то полезное даже без совпадения в каталоге — иначе девочки бросят через три попытки.

- **Лестница статусов:** 🔍 Загадка → 🧩 Есть зацепки → 📅 Эпоха определена → 📖 Найдена в каталоге. Прогресс: «раскрыто 3 из 12».
- **Улики копятся в карточке:** клеймо, эпоха, материал, похожие страницы, номер патента, если девочка его вписала.
- **Датировка по признакам** (застёжка, крепление камней, металл, замочек, конструкция) по историческим книгам Кристины — со ссылкой на страницу. Так её большая историческая библиотека работает на определение.
- **Уведомления:** «В библиотеку пришла книга, где может быть твоё украшение».
- **Компактный вид:** карточка одним сообщением (фото + короткая подпись), подробности под кнопкой; список — альбом миниатюр по 10; редактирование и удаление меняют то же сообщение, а не создают новые.
- **Потом — Telegram Mini App:** галерея шкатулки с сеткой и фильтрами внутри Telegram, мост к отдельному приложению.

### 4. «Ценно — неценно»

Быстрый опросник для рынка, 4–5 нажатий, без ИИ:

- Есть проба или клеймо металла?
- Подпись фирмы?
- Камни в лапках или на клею?
- Какая застёжка?
- Состояние?

На выходе: «⭐ сигналы коллекционной вещи: 3 из 5 — стоит рассмотреть». Вопросы и правила пишет Кристина — это её экспертиза в кнопках. Стоит ноль.

### 5. Группа, которая живёт без Кристины

- **Статья из библиотеки.** По расписанию или по команде («бакелит», «паста XVIII века», дизайнер) Люся пишет короткий пост по книгам со ссылками на страницы и **сначала присылает черновик Кристине**: «Опубликовать» / «Переделать». По оценке — доли цента за пост. Пересказ, а не копирование страниц; сканы из книг не публикуются; фото — только собственные Кристины.
- **«Загадка недели».** Фото украшения (Кристины или из шкатулок с согласия владелицы), девочки угадывают эпоху и фирму, через пару дней — ответ.
- **«Раскрыто на этой неделе».** Дайджест решённых загадок из шкатулок, с согласия.
- **Темы группы:** 18 тем → 13, схема согласована с Кристиной:

# Lucy Research Engine — аудит и выбор решения

_Ноябрь 2026. Документ для Кристины и для любого, кто работает с кодом Люси._

Цель: Люся должна исследовать винтажные украшения почти так же хорошо, как
Claude или ChatGPT с поиском, но с преимуществом — своей библиотекой книг
со страницами, шкатулкой и экспертизой Кристины. Главное правило:
ничего не выдумывать и честно различать «подтверждено», «предполагается»
и «неизвестно».

## 1. Аудит: что Люся умеет сейчас

| Режим | Как работает | Ограничение |
| --- | --- | --- |
| «📚 Найти информацию» (`library_ai`) | Текстовый поиск по OCR → 3 страницы → до 4 фрагментов, всего ≤ 6 000 знаков → gpt-4.1-mini пересказывает со ссылками | Модель видит 4 коротких куска. Сложную атрибуцию так не сделать. Интернета нет |
| Свободные вопросы (`lucy_ai`) | gpt-4.1-mini отвечает из своих знаний | Без источников, возможны выдумки |
| Исследование карточки (`attribution`) | ИИ описывает 3 фото → кандидаты-страницы **по тексту** (клеймо, описание) → сравнение фото с 4 картинками страниц | Если украшения нет в подписях, страница не найдётся. Интернета нет. Это не визуальный поиск |
| `/article` (админ) | Все страницы темы по этапам → досье | Только книги, только тема (не предмет) |

Учёт денег: свои отдельные журналы у атрибуции (`visual_ai_calls`) и
у `/article` (`library_article_calls`). У «Найти информацию» и свободных
вопросов фактическая стоимость **не записывается** — только счётчики
вопросов. Общего месячного бюджета нет.

Главные причины, почему Люся ищет хуже, чем Claude/ChatGPT:
1. Слабая модель (gpt-4.1-mini) и очень мало текста книг на входе.
2. Нет интернета: ни справочников клейм, ни музеев, ни аукционов.
3. Нет проверки ответа: ссылки на страницы проверяются, но
   «предположение» и «факт» не разделяются.

## 2. Три уровня исследования

| Уровень | Для чего | Модель | Источники | Оценка цены |
| --- | --- | --- | --- | --- |
| ⚡ Быстрый | Обычные вопросы | дешёвая (gpt-4.1-mini, как сейчас) | книги | ≈ 0,2 цента |
| 🔬 Исследование украшения | Карточка шкатулки | сильная (`LUCY_RESEARCH_MODEL`) + зрение | фото, карточка, книги (до 12 страниц целиком), интернет (3–4 запроса) | ≈ 3–8 центов |
| 🧭 Глубокая атрибуция | Сложные предметы | сильная + второй проход «критик» | то же + до 25 страниц книг, 8 целевых интернет-запросов: справочники клейм, музеи, аукционы, патенты | ≈ 8–25 центов |

Каждое исследование и глубокая атрибуция запускаются **только по кнопке**
после показа плана и цены, повторное нажатие не создаёт второй платный
запуск, готовый результат по тем же данным открывается бесплатно.

## 3. Интернет-поиск: сравнение

Цены — из открытых обзоров ноября 2026; официальные страницы из среды
разработки не открылись. **Перед подключением сверить** на сайтах
сервисов. В коде все цены — настройки, а расходы считаются по
фактическим данным ответа.

| Вариант | Цена | Что возвращает | Плюсы | Минусы |
| --- | --- | --- | --- | --- |
| **Tavily Search API** | 1 000 кредитов в месяц бесплатно; дальше ≈ $0,008 за кредит; базовый поиск 1 кредит, расширенный 2 | Заголовок, URL, **текст страницы** (сниппет или полный), картинки | Сделан для ИИ: текст сразу пригоден как доказательство; фильтр по доменам (аукционы, музеи); бесплатного лимита хватает на пилот | Сторонний сервис, нужен ключ |
| Brave Search API | ≈ $5 за 1 000 запросов, по некоторым данным $5 в месяц бесплатно | Заголовок, URL, короткий сниппет | Свой независимый индекс | Мало текста — придётся отдельно скачивать страницы |
| Exa | ≈ $7 за 1 000 запросов с текстом | URL + текст/выдержки | Хороший семантический поиск | Дороже, бесплатный лимит неясен |
| Встроенный web_search OpenAI | ≈ $10–25 за 1 000 вызовов **плюс** токены найденного текста; один вызов может делать несколько поисков | Ответ модели со ссылками | Ничего не подключать | Нет текста источника для проверки, цена непредсказуема (в замерах в 2–3 раза выше ожидания) |
| Perplexity Sonar | ≈ $5–14 за 1 000 запросов + токены | Готовый ответ со ссылками | Просто | По ряду источников Sonar переведён в другой API; это «чужой исследователь», а не источники |
| Google Lens через SerpAPI и т.п. | от десятков $ в месяц | Поиск по картинке | Настоящий поиск аналогов по фото | Не помещается в бюджет €10 |

**Выбор: Tavily** как основной поставщик, через общий интерфейс
`web_search.Provider` — Brave или Exa подключаются заменой одного класса.

Почему не самый дешёвый и не встроенный OpenAI:
- Tavily отдаёт **текст найденной страницы**. Люся передаёт ИИ
  пронумерованные интернет-источники `[W1]…`, и код проверяет, что каждая
  ссылка в ответе есть среди реально найденных — как сейчас со страницами
  книг. Выдумать URL нельзя.
- По тексту источника код проверяет, что «продано за» — это реальная
  продажа (sold / realized / hammer price на аукционном сайте), а не цена
  объявления.
- Число запросов фиксировано (3–4 или 8), значит цена предсказуема.
- 1 000 бесплатных кредитов в месяц ≈ 120–250 исследований.

## 4. Модель

Цены моделей быстро меняются, названия тоже (в ноябре 2026 на странице
цен OpenAI — семейство GPT-6). Поэтому:
- модель для исследования задаётся переменной `LUCY_RESEARCH_MODEL`;
  по умолчанию `gpt-4.1` (сильнее mini, была в API давно);
- цены — `LUCY_RESEARCH_PRICE_INPUT_PER_M` / `..._OUTPUT_PER_M`;
  если цена модели неизвестна, Люся считает по завышенной ($10 / $40 за
  1 млн) и предупреждает администратора;
- рекомендуемая настройка: модель среднего уровня из актуального списка
  OpenAI с поддержкой изображений (по обзорам ≈ $1–2 вход / $5–10 выход
  за 1 млн токенов). Кристина выбирает в кабинете OpenAI, какая доступна.

## 5. Проверяемая атрибуция — формат ответа

ИИ возвращает JSON, бот проверяет и оформляет:

- предварительное определение и уверенность (низкая / средняя / высокая);
- признаки, на которых оно основано;
- **что модель действительно рассмотрела на фото** — отдельно от того,
  что найдено по тексту;
- сведения из книг `[n]` → книга, DOC, страница из базы;
- интернет-источники `[Wn]` → реальные ссылки из поиска;
- аналоги: что совпадает и чем отличается, со ссылкой на источник;
- цены: «продажа на аукционе» / «цена объявления» / «оценка» — тип
  проверяется кодом;
- подтверждено / предполагается / неизвестно; что сделать дальше.

Код удаляет: ссылки на несуществующие источники, утверждения в разделах
доказательств без ссылок, аналоги и цены без источника. Число удалённого
записывается — это метрика «необоснованные утверждения» для испытаний.
Без единого подтверждающего источника уверенность не может быть выше
«низкой». Клеймо, записанное владелицей, — главный факт.

## 6. Бюджет

- Общий журнал фактических расходов `ai_spend` (OpenAI и поиск) +
  уже существующие журналы атрибуции и `/article`.
- Общий месячный бюджет `LUCY_AI_BUDGET_MONTH_USD` (по умолчанию 11 —
  ≈ €10). При 50 %, 80 % и 100 % — сообщение администратору.
  После 100 % платные вызовы останавливаются для всех.
- Перед вызовом — резерв оценки; после — фактическая стоимость по токенам
  из ответа. Оценка — не гарантия, поэтому обязательна **вторая стена** на
  стороне сервисов: предоплаченный баланс OpenAI без автопополнения
  (или бюджет проекта) и бесплатный план Tavily без карты.
- Администратор — без персональных лимитов, но в общем бюджете.
  Тестировщицы — месячные лимиты на исследования.

## 7. Испытания

Пять реальных украшений из шкатулки с известной Кристине атрибуцией.
Сравнение «старая Люся» (атрибуция по книгам) и «новая» (исследование и
глубокая атрибуция) по: правильности, качеству аналогов, достоверности
источников, числу необоснованных утверждений, стоимости. Протокол —
`docs/RESEARCH_TRIALS.md`. Результаты не придумываются: прогон — только
после согласия Кристины на платные запросы.
